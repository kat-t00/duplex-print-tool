# 両面印刷PDF整形ツール

利用者ごとに枚数がバラバラな書類（サービス利用票など）を、両面一括印刷しても
利用者ごとの区切りがズレないように白紙ページを自動挿入するツール。

## 使い方
1. https://kat-t00.github.io/duplex-print-tool/ を開く
2. 利用者分をまとめて結合したPDFをアップロード
3. 「白紙ページを挿入して整形する」をクリック
4. 出力されたPDFをダウンロードして両面印刷

## 仕組み
- 各ページの本文から「〇〇 様」という名前をPDF.jsで検出
- 同じ名前が連続するページを1人分としてグループ化（名前が読めないページは直前の人の続きとして扱う）
- グループのページ数が奇数なら白紙ページを1枚追加（偶数ページ=両面印刷で次の人が新しい用紙から始まる）
- pdf-libで結合し直して1つのPDFとして出力

処理はすべてブラウザ内で完結し、ファイルはどこにもアップロードされません。

## 元ネタ
もともとはWindows専用のPython/tkinterデスクトップアプリ（`.exe`、pdfplumber + pypdf使用）として
事業所内で使っていたものを、誰でもブラウザだけで使えるように移植した。
